# EXE CHAT · Cozy Cabin

Animated chat widget for StreamElements (Twitch) by **form&soul.exe**.
Chat messages hang from a snowy wooden sign and flip in when new ones arrive; a little fox lives on the porch and reacts to the chat, to 12 viewer commands and to subs, follows, raids, bits and tips.

This repository hosts the images, sounds, font and engine that the widget loads. **Do not rename or move files**: installed widgets load them from these URLs.

- Preview: https://feder0707.github.io/exe-chat-assets/
- Engine: `engine/exechat.js` (version in the first line)
- Installation: paste `HTML`, `CSS`, `JS` and `FIELDS` from your purchase into a StreamElements custom widget.

Viewer commands: `!pet !cookie !cocoa !snowball !dance !nap !boo !tail !hug !howl !blanket !wave` (each can be renamed or turned off).
